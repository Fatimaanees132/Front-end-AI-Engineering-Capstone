# Case Study 1

## Project

Professional Login Page – Frontend AI Engineering Capstone

## Problem

The goal of this project was to build a professional login page for a frontend AI engineering capstone project. The login page needed to provide a secure, accessible, and responsive authentication interface while matching the existing design system. Instead of introducing a new visual style, the focus was on creating a consistent user experience and applying frontend engineering best practices using HTML, CSS, and vanilla JavaScript.

## What I Did

I designed and implemented the core frontend functionality of the login page. To keep the experience consistent with the rest of the project, I reused the existing color palette, typography, spacing, and overall design language rather than creating a separate design.

From a technical perspective, I used semantic HTML, responsive CSS, and vanilla JavaScript to keep the implementation lightweight and easy to maintain. I added client-side validation for email and password fields, a password show/hide toggle, loading feedback during sign-in, and accessibility improvements such as proper form labels and keyboard-friendly navigation.

One of the main challenges was balancing new functionality with visual consistency. I wanted to include modern usability features without making the page feel disconnected from the existing application. I addressed this by following established design patterns and limiting the implementation to the functionality required for authentication. I also chose vanilla JavaScript over external libraries to keep the code simple and easier to integrate.

## Outcome

The final result is a professional, responsive, and accessible login page that integrates smoothly with the existing project. It provides users with a clean authentication experience, client-side validation, clear feedback, and a consistent interface across different devices.

This project strengthened my understanding of responsive frontend development, accessibility, and writing clean, reusable code while working within an established design system.
