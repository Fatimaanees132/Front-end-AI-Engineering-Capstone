# AI Workflow Comparison

This exercise compared two different approaches to using AI for software development. In the first round, I used a very vague prompt: "Create a settings form for my website." The AI generated a working solution, but it also made many assumptions. It created a much larger application than required, including AI preferences, privacy controls, appearance settings, and many additional UI components. Although the code was functional, it required significant review to determine what was actually relevant to the assignment. The implementation was more complex than necessary and would have taken extra time to simplify.

In the second round, I used a detailed prompt with clear requirements, file references, constraints, accessibility expectations, and a verification step. Before generating code, the AI explained its implementation plan and then produced a focused solution containing only the requested settings form. The generated HTML used semantic elements and accessible labels. The CSS was organized into logical sections with comments, and the JavaScript included structured validation, whitespace trimming, inline error handling, and success feedback. The final implementation was easier to understand and required much less manual review.

Comparing both approaches showed that prompt quality directly affects development efficiency. Although writing the detailed prompt took longer initially, it reduced the amount of time spent reviewing, removing unnecessary code, and fixing issues afterward. The vague prompt produced a larger output with many assumptions, while the structured prompt stayed aligned with the requirements.

One AI mistake I identified in the first version was that it generated many unnecessary settings and features instead of the small form requested in the assignment. This increased complexity and review effort without adding value. From this exercise, I learned that providing explicit requirements, constraints, accessibility expectations, and verification instructions results in higher-quality code and a more efficient development workflow.
